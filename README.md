## 🔓 Open-Source GitHub Projects

*Sorted by GitHub_Stars_Count (Descending)* 🌟

- **[Ansible](https://github.com/ansible/ansible)** [![Stars](https://img.shields.io/github/stars/ansible/ansible?style=social&color=white)](https://github.com/ansible/ansible/stargazers) ⚡  
  **Radically simple IT and network automation engine**, GPL-2.0 licensed. **70,864+ stars**. Agentless automation for network configuration, multi-vendor device orchestration, playbook execution, and infrastructure deployment across Cisco, Juniper, Arista, and Linux systems.

- **[NetBox](https://github.com/netbox-community/netbox)** [![Stars](https://img.shields.io/github/stars/netbox-community/netbox?style=social&color=white)](https://github.com/netbox-community/netbox/stargazers) 📦  
  **The cornerstone of every automated network**, Apache-2.0 licensed. **21,658+ stars**. **IPAM and DCIM tool** that serves as the central source of truth for network infrastructure. Comprehensive data model: racks, devices, cables, IPs, VLANs, circuits, power, VPNs. Programmatic REST and GraphQL APIs for network automation pipelines.

- **[Zabbix](https://github.com/zabbix/zabbix)** [![Stars](https://img.shields.io/github/stars/zabbix/zabbix?style=social&color=white)](https://github.com/zabbix/zabbix/stargazers) 📊  
  **Enterprise-class open-source distributed monitoring solution**, AGPL-3.0 licensed. **6,442+ stars**. Monitors performance and availability of network devices, servers, VMs, and cloud infrastructure. SNMP polling, auto-discovery, distributed proxies, root cause analysis, and real-time alerting.

- **[LibreNMS](https://github.com/librenms/librenms)** [![Stars](https://img.shields.io/github/stars/librenms/librenms?style=social&color=white)](https://github.com/librenms/librenms/stargazers) 📈  
  **Community-based auto-discovering network monitoring system**, GPL-3.0 licensed. **4,940+ stars**. Fully featured SNMP-based network monitoring platform. Supports auto-discovery, custom alerting, billing calculations, horizontal scaling, and integrations with Oxidized & Graylog.

- **[Oxidized](https://github.com/ytti/oxidized)** [![Stars](https://img.shields.io/github/stars/ytti/oxidized?style=social&color=white)](https://github.com/ytti/oxidized/stargazers) 💾  
  **Network device configuration backup tool**, Apache-2.0 licensed. **3,598+ stars**. Automatically fetches and backs up configurations from 100+ network device vendors (Cisco, Juniper, Arista, Huawei). Supports Git repository versioning and REST API integration.

- **[phpIPAM](https://github.com/phpipam/phpipam)** [![Stars](https://img.shields.io/github/stars/phpipam/phpipam?style=social&color=white)](https://github.com/phpipam/phpipam/stargazers) 🏷️  
  **Open-source IP address management platform**, GPL-3.0 licensed. **2,811+ stars**. Web-based IPAM software supporting IPv4/IPv6 address allocation, subnet mapping, VLAN management, VRF tracking, SNMP scanning, and REST API automation.

- **[Ralph](https://github.com/allegro/ralph)** [![Stars](https://img.shields.io/github/stars/allegro/ralph?style=social&color=white)](https://github.com/allegro/ralph/stargazers) 🏢  
  **CMDB and Asset Management system for data centers**, Apache-2.0 licensed. **2,522+ stars**. Lightweight asset management tool with DCIM capabilities for tracking hardware, rack positions, patch panels, data center power, and domain infrastructure.

- **[NAPALM](https://github.com/napalm-automation/napalm)** [![Stars](https://img.shields.io/github/stars/napalm-automation/napalm?style=social&color=white)](https://github.com/napalm-automation/napalm/stargazers) 🐍  
  **Network Automation and Programmability Abstraction Layer with Multivendor support**, Apache-2.0 licensed. **2,509+ stars**. Cross-vendor Python library providing a unified API to manipulate network device configurations and retrieve operational data.

- **[Checkmk](https://github.com/Checkmk/checkmk)** [![Stars](https://img.shields.io/github/stars/Checkmk/checkmk?style=social&color=white)](https://github.com/Checkmk/checkmk/stargazers) 🛡️  
  **Comprehensive IT infrastructure monitoring platform**, GPL-2.0 licensed. **2,386+ stars**. Powerful monitoring solution featuring auto-discovery, rule-based configuration, high-performance metric collection, and 2,000+ official check plugins.

- **[Cacti](https://github.com/Cacti/cacti)** [![Stars](https://img.shields.io/github/stars/Cacti/cacti?style=social&color=white)](https://github.com/Cacti/cacti/stargazers) 🌵  
  **Network graphing and data collection framework**, GPL-2.0 licensed. **1,874+ stars**. Robust web-based network graphing solution utilizing RRDtool for bandwidth monitoring, SNMP data polling, user management, and template-based device views.

- **[PacketFence](https://github.com/inverse-inc/packetfence)** [![Stars](https://img.shields.io/github/stars/inverse-inc/packetfence?style=social&color=white)](https://github.com/inverse-inc/packetfence/stargazers) 🔒  
  **Fully featured Network Access Control (NAC) solution**, GPL-3.0 licensed. **1,697+ stars**. Provides captive portal registration, 802.1X authentication, BYOD onboarding, vulnerability scanning, and guest network isolation across multi-vendor switch/wireless hardware.

- **[Nornir](https://github.com/nornir-automation/nornir)** [![Stars](https://img.shields.io/github/stars/nornir-automation/nornir?style=social&color=white)](https://github.com/nornir-automation/nornir/stargazers) ⚙️  
  **Pluggable multi-threaded automation framework in Python**, Apache-2.0 licensed. **1,625+ stars**. High-performance network automation framework designed for Python developers, offering task concurrency, inventory management, and zero domain-specific language overhead.

- **[Nautobot](https://github.com/nautobot/nautobot)** [![Stars](https://img.shields.io/github/stars/nautobot/nautobot?style=social&color=white)](https://github.com/nautobot/nautobot/stargazers) 🤖  
  **Network Source of Truth and Automation Platform**, Apache-2.0 licensed. **1,622+ stars**. Extensible Django-based network model and application platform for IPAM/DCIM, enterprise network automation, GraphQL data queries, and custom workflow execution.

- **[OpenNMS Horizon](https://github.com/opennms/opennms-core)** [![Stars](https://img.shields.io/github/stars/opennms/opennms-core?style=social&color=white)](https://github.com/opennms/opennms-core/stargazers) 🌐  
  **Enterprise-grade open-source network management platform**, AGPL-3.0 licensed. **1,174+ stars**. Highly scalable distributed event management, fault monitoring, performance metric collection, and network discovery engine.

- **[OpenWISP Controller](https://github.com/openwisp/openwisp-controller)** [![Stars](https://img.shields.io/github/stars/openwisp/openwisp-controller?style=social&color=white)](https://github.com/openwisp/openwisp-controller/stargazers) 📡

- **[flexiWAN](https://github.com/flexiwan)** [![Stars](https://img.shields.io/github/stars/flexiwan/agent?style=social&color=white)](https://github.com/flexiwan/agent/stargazers) 🔀

## ⚠️ Disclaimer

- This is a **community-curated** list — not exhaustive and not an official endorsement. ℹ️
- Commercial network controllers (Cisco DNA Center, Juniper Mist, Aruba Central) provide AI-driven insights but primarily manage their own hardware ecosystems, creating **vendor lock-in**. Open-source alternatives like NetBox, Zabbix, Ansible, and OpenWISP explicitly aim to eliminate this lock-in by supporting multi-vendor environments.
- **OpenWISP** is designed primarily for OpenWrt/Linux devices. **flexiWAN** requires x86-based hardware. **NetXMS**, **Checkmk**, and **Zabbix** scale from small home labs to enterprise deployments with proper architecture.
- Open-source network management tools provide self-hosted ownership and transparency, but enterprise-grade SLA guarantees, 24/7 support, and managed cloud infrastructure remain primarily commercial offerings. **Always validate network changes in a lab environment** before applying to production networks. 🌐
